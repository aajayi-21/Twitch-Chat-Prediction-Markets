# Twitch-Chat-Prediction-Markets
Kalshi/Polymarket-like prediction markets in Twitch Chat using channel point

## Overview

- Utilizes a central limit order book data structure to implement prediction-market like functionality in Twitch using channel points as currency

**Example Usage**

"Buy ten shares of yes at 40 channel points"

!buy yes 40 10

"Sell ten shares of no at 55 channel points"

!sell no 55 10

- Implementation of the order book based on https://github.com/bigfatwhale/orderbook
